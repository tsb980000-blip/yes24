# 교보문고 데이터 수집 스크립트 작성 및 검증 요약 (Walkthrough)

## 완료된 작업 (Changes made)
- **요구사항 정의**: 사용자와의 상호작용(`/grill-me`)을 통해 교보문고 IT/컴퓨터 카테고리의 베스트셀러 목록을 가져와 CSV로 저장하는 요구사항을 확정했습니다. 이후 URL의 `page` 파라미터를 동적으로 변경해 전체 페이지 데이터를 수집하도록 요구사항(`scraping_prompt.md`)을 추가 수정했습니다.
- **프로젝트 구조 세팅**: `kyobobooks` 폴더 내에 `docs`, `src`, `data`, `images` 하위 디렉토리를 생성했습니다. (가상환경은 워크스페이스의 공통 `.venv` 사용)
- **스크립트 작성 및 개선**: `kyobobooks/src/scraper.py`에 파이썬 `requests`와 `csv` 라이브러리를 활용하여 로직을 구현했습니다.
  - API의 실제 JSON 응답 구조를 파악하여 올바른 키값에서 데이터를 추출하도록 했습니다.
  - `while` 반복문과 `time.sleep()`을 적용해 1페이지부터 마지막 페이지까지 데이터를 순회하며 수집하도록 고도화했습니다.
  - 파일 최상단에 Docstring 규칙을 준수하여 작성 목적과 설명을 포함했습니다.

## 테스트 내역 (What was tested)
- API 엔드포인트 단일 호출 검증 및 JSON 응답 구조(`keys`) 디버깅
- `uv run python kyobobooks/src/scraper.py` 명령어를 통해 전체 페이지 순회 스크립트 백그라운드 실행 및 페이징 로직 테스트

## 검증 결과 (Validation results)
- 스크립트가 1페이지부터 50페이지까지 성공적으로 순회하며 호출되었습니다.
- 총 **1000개**의 베스트셀러 도서 데이터가 추출되어 지정한 경로(`kyobobooks/data/best_sellers.csv`)에 정상적으로 저장되었습니다.
- CSV 파일 내에 `순위`, `도서명`, `저자`, `출판사`, `정가`, `판매가` 컬럼이 정확히 매핑되었으며, 한글 깨짐 없이 올바른 포맷으로 보존됨을 확인했습니다.
